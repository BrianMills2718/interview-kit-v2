# Interview kit v2: what to use when

Seven short guides for a timed agentic-AI / data-science take-home done with an AI chat. Each guide
has **Always** (do it on every task) and **When to use what** (pick by situation), plus short
prompts to type.

| # | Guide | Answers |
|---|---|---|
| 1 | [Workflow and prompts](1-workflow.md) | What do I do, in what order, and what do I type? |
| 2 | [Documents](2-documents.md) | Which documents do I write (PRD, use cases, ADRs, plan, README), and when? |
| 3 | [Models and diagrams](3-models.md) | Which diagrams do I draw, and which question does each answer? |
| 4 | [LangChain and LangGraph](4-agents.md) | Plain code, an agent or a graph? Tools, pauses, memory, limits, and the traps. |
| 5 | [Data science techniques](5-data-science.md) | Which statistic, test, detector or text/network method fits this data? |
| 6 | [Evaluation](6-evaluation.md) | How do I show a model, classifier or agent works? |
| 7 | [Tests and code quality](7-tests.md) | What do I test, how, and what makes the code read well? |

Practice problems with graders are in the first kit:
[interview-kit/practice3](https://github.com/BrianMills2718/interview-kit/blob/main/practice3/PROBLEM.md)
(data science), `practice2` and `practice` (agent mechanics).
